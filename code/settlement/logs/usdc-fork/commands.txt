Real USDC gas and buyer burden: how each file here was made.
Code: branch release-units at 2e15f8d (contracts and client unchanged); new files only:
  contracts/test/sdk/usdcfork/{UsdcFork.sol, UsdcReleaseGasFork.t.sol, UsdcReleaseLoadFork.t.sol,
    UsdcAnchorLoadFork.t.sol, UsdcBuyerGasFork.t.sol, MockOnFork.t.sol}
  scripts/compare_usdc_gas.py, adapters/signing-client/bench/buyer-burden.ts
Tools: forge 1.7.1, anvil 1.7.1, solc 0.8.24 (sdk profile: via-IR, optimizer runs 1, Osaka), node 22.23.4.

The fork. Base state at block 52977000 (the block of the earlier fork runs), served by a local anvil
node with chain id 31337:
  anvil --fork-url https://mainnet.base.org --fork-block-number 52977000 --chain-id 31337 --port 8547
forge run directly against Base (chain id 8453) treats the chain as OP-stack and charges each --isolate
transaction an L1 data fee in ETH; SdkBase._newSettlement deals the test contract exactly 100 ETH and
sends all of it to the VRF mock, so setUp reverts there (seen with forge --fork-url https://mainnet.base.org
--isolate, also with --gas-price 0, --block-base-fee-per-gas 0, vm.fee(0), vm.txGasPrice(0) and
--network ethereum). Gas used does not depend on the fee. FiatTokenV2_2 takes its EIP-712 domain from
block.chainid and the tests sign against token.DOMAIN_SEPARATOR(), so USDC's checks run unchanged.
Funding: the fork's USDC master minter (impersonated with vm.prank) configures the test contract as a
minter, and the tests' own token.mint calls are USDC mints (UsdcFork.sol). No real funds, no keys
(test keys are the tests' fixed hashes; the benchmark generates throwaway keys in memory).

Every forge run: FOUNDRY_PROFILE=sdk forge test --isolate --gas-limit 9223372036854775807 \
  --fork-url http://127.0.0.1:8547 -vv <selection>
